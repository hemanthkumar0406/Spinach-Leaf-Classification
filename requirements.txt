## ⚙️ Run Locally

```bash
# 1. Clone the repo
git clone https://github.com/hemanthkumar0406/Spinach-Leaf-Classification.git
cd Spinach-Leaf-Classification

# 2. Install dependencies
pip install -r requirements.txt

# 3. Place model checkpoint
# Copy mobilenet_best.pth into models/ folder

# 4. Run the app
python app.py

# 5. Open browser
# http://127.0.0.1:7860
```
